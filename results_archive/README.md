# Archived transcripts

`ramp_6turn_handverified/` holds the original six-turn `compounding_ramp` runs.

These are the transcripts behind the findings in [../FINDINGS.md](../FINDINGS.md).
Their verdicts were established by **reading the final answers by hand**, because
the automated probe could not reliably decide which figure a free-prose reply
committed to (see METHODOLOGY.md §7). They are published unmodified so anyone can
check that reading against the source.

The live scenario now has a seventh turn demanding a bare number, which makes the
commitment machine-decidable. Runs in `../results/` use that version.
